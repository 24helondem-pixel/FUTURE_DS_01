# Task 2 — Customer Retention & Churn Analysis

## Objective
Analyze customer churn patterns, compare customer segments, and recommend retention actions.

## Dataset
`data/customer_churn.csv` contains 7,043 reproducibly generated synthetic telecom-style records. This is demonstration data, not real customer data.

## Google Colab
Upload `customer_churn.csv` and run `notebooks/Task_2_Churn_Analysis.ipynb`.

## Streamlit
Install dependencies with `pip install -r requirements.txt`, then run `streamlit run app.py`.

## Metrics and analysis
Churn rate, retention rate, customer count, contract type, tenure, payment method, and monthly charge bands.

## Integrity note
Do not present synthetic results as actual business/customer findings.
